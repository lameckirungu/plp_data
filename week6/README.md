## Deliverables

### Part A — Technical Notebook
**`notebooks/week6_stats_and_pdm.ipynb`**

- **Statistical Validation:** independent t-test (Day vs Night vibration, p=0.0026),
  ANOVA across depots (pressure, p<0.0001), 95% confidence intervals, plain-English
  interpretation, boxplot and histogram visualisations
- **PdM Feature Engineering:** verified the 4 pre-existing rolling features, added 2 new
  ones (rolling std, trend slope), 3-panel degradation visualisation showing raw signal →
  engineered features → health status classification over time
- **Predictive Modeling:** Logistic Regression (94.2% accuracy, 84.3% sensitivity, 2.4%
  false alarm rate) for 7-day failure risk; Linear Regression (MAE 105.9 hours) for
  Remaining Useful Life; confusion matrix and actual-vs-predicted visualisations;
  documented business implications for both models
